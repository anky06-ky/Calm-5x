# CalmX Digital Orbit

Website giới thiệu dự án CalmX của đội Khát Vọng tại HUIT STARTUP 2026.

## Chạy dự án

Yêu cầu Node.js 18 trở lên.

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Build production

```bash
npm run build
npm run preview
```

## Công nghệ

- React 18
- Vite
- Lucide React
- Canvas Confetti
